# Folio Universal

A portable document reader for keeping different kinds of reading in one place.

## What is Folio?

Folio Universal is a portable reader for keeping different document types in one simple browser interface. The release is a single HTML file with its libraries included; no account or server is needed.

## Supported documents

- Markdown and text files, including common text-based formats.
- DOCX with headings, lists, tables and embedded images; old DOC files are supported as text where possible.
- PDF pages, bookmarks and searchable text layers.

## Features and use

Download the ZIP from [Releases](https://github.com/FajkPes/Folio-Universal/releases/latest) and open `Folio_Universal.html` in a modern browser. Open a document, navigate its chapters, search its text and continue from the saved position. The library keeps up to ten documents, with up to four pinned.

Use **Export library** and **Restore backup** before moving to another browser or computer: the library belongs to the browser's storage, not the HTML file. PDF OCR and form editing are not provided, and DOCX layout is adapted for reading rather than reproduced exactly. The current interface is in Czech.

[Detailed documentation](README-DETAILS.md) · [All releases](https://github.com/FajkPes/Folio-Universal/releases)

## Reading and keeping your place

Folio combines chapter navigation, search, folding and a remembered reading position in the same interface for several document types. Its library can hold ten documents, four of which can be pinned. Pinned items are protected from automatic replacement by the app, not from browser-storage deletion. Export a library backup before clearing browser data or changing browser or device.
