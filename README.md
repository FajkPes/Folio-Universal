# Folio Universal

A portable document reader for keeping different kinds of reading in one place.

## Key features

- Open Markdown, text, PDF, DOCX and text from supported DOC files.
- Search, navigate chapters and return to your last position.
- Keep a small local library and export a backup.

## Get started

Download the ZIP from Releases and open `Folio_Universal.html` in a modern browser. The interface is currently in Czech.
